# StayEase - Hotel Booking System

StayEase is a frontend hotel booking application built using React and Vite.

## Features

- Home page
- User signup page
- User login page
- Browse available hotels
- View hotel details
- Book hotels
- View booking history
- Logout functionality

## Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS
- React Router DOM
- Local Storage
